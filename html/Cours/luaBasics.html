Introduction to RbxLua

RbxLua is the scripting language used in Roblox. It is based on Lua 5.1, but includes additional features and APIs specific to Roblox. This guide covers the basics of RbxLua, including syntax, variables, functions, and how to interact with the Roblox environment.

Variables

Variables are used to store data. In RbxLua, you declare a variable using the local keyword. 

-- Declare a variable
local playerName = "JoeMama"
local playerHealth = 100
local isAlive = true

-- Print variables
print(playerName)
print(playerHealth)
print(isAlive)

Data Types

RbxLua supports several data types: nil, boolean, number, string, table, function, userdata, and thread. 

-- Example of data types
local nothing = nil -- means No value
local isTrue = true -- boolean
local score = 1500 -- number
local greeting = "Welcome to Roblox!" -- string
local age = 25 -- number
local name = "Roblox" -- string
local inventory = {"sword", "shield", "potion"} -- table
local playerStats = {health = 100, mana = 50} -- table with key-value pairs 
local if printHello = function() print("Hello!") end -- function

Functions

Functions are blocks of code that perform a specific task. You can define a function using the function keyword. 

-- Define a function
local function addNumbers(a, b)
    return a + b
end

-- Call the function
local result = addNumbers(5, 3)
print(result) -- Output: 8

Control Structures

Control structures allow you to control the flow of your program. RbxLua includes if, for, while, and repeat statements. 

-- If statement
local age = 18
if age >= 18 then
    print("You are an adult.")
else
    print("You are a minor.")
end

-- For loop
for i = 1, 5 do
    print("Count: " .. i)
end

-- While loop
local count = 0
while count < 5 do
    print("While count: " .. count)
    count = count + 1
end

Events

Events are used to respond to actions in Roblox, such as a player joining or a part being touched. 

-- Example: Player joins the game
game.Players.PlayerAdded:Connect(function(player)
    print(player.Name .. " has joined the game!")
end)

-- Example: Part is touched
local part = workspace.Part
part.Touched:Connect(function(otherPart)
    print("Part was touched by: " .. otherPart.Name)
end)

Roblox API

The Roblox API provides access to game objects, services, and properties. You can manipulate the game world using these APIs. 

-- Example: Change a part's color
local part = workspace.Part
part.BrickColor = BrickColor.new("Bright red")

-- Example: Spawn a new part
local newPart = Instance.new("Part")
newPart.Parent = workspace
newPart.Position = Vector3.new(0, 10, 0)
